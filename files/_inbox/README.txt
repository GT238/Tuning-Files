SUBMISSION DROP ZONE (not published)
====================================

Files placed in this folder are NOT published to the site -- the catalog
generator skips any folder starting with "_".

To submit a file:
  1. Drop the .bin / .xdf / etc. here.
  2. Include a note (text file or email) with: vehicle, engine, years,
     transmission, and where the file came from (source).
  3. The maintainer verifies it (checksum, embedded OS/CAL ID check,
     duplicate check -- all automatic), writes the metadata entry, moves it
     into the archive tree, and rebuilds the site.

Do not flash anything from this folder -- submissions are unreviewed.
