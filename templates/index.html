Tuning Files Archive

A searchable library of ECU/PCM calibration files (.bin), XDF definitions, and tunes.

Have a calibration or definition to share? ⤴ Submit a file — submissions are auto-checked (checksum, duplicates, OS ID) and published by a maintainer after review.

Always verify a download against its SHA-256 checksum before flashing. Checksums for every file are listed in sha256sums.txt at the archive root.

Badges: stock/tune/xdf file type  •  needs info metadata incomplete  •  ID? claimed OS ID not found inside the bin — verify before use  •  verified checksum confirmed against a known-good copy  •  ⧉ duplicate of = byte-identical to another archived file (keep one, delete the rest if you like).

Have a calibration or definition to share? Submit it for review — submissions get automatic checks (checksum, duplicates, embedded OS/CAL ID) before a maintainer publishes them.

Calibration files are the property of their respective manufacturers and are shared here for personal / educational use only. If you own a copyright to any file here and want it removed, open an issue and it will be handled promptly.
